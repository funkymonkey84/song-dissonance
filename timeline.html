How events were chosen

To avoid picking events that fit the numbers, the rules were set before the history was researched:

  • An event is included if it appears in a standard history or reference work for that decade, and it has a documented link to music (how music was made, distributed, or discussed).
  • Each decade gets the same number of events in each area.
  • Every entry has a source. One entry per decade deliberately complicates the story.

Links between history and the data are offered as “consistent with,” not as causes. [to add: date the rules were written]
